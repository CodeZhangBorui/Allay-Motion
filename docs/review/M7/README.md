# M7 导出完善：评审说明

**要人确认的**（`docs/08-milestones.md` M7）：把四种格式各导一个，放进自己常用的剪辑软件试一遍，记下哪个软件认哪种格式。自动测试只验证了文件本身（色彩标记、帧数、透明通道的回读），**没有在任何剪辑软件里看过**。

**导出四个文件**（`pnpm dev` 打开应用，默认模板“方块擦除”）：顶栏“导出”右侧的小箭头 → 选格式 → 对话框里“输出位置”点“更改…”，选仓库下的 `out/`（被 git 忽略）→ “导出”。四种格式各一次：透明 MOV（ProRes 4444）、PNG 序列、透明 WebM（VP9）、绿幕 MP4（H.264）。完成页有“在文件夹中显示”，并写着剪辑点是第几帧。

**在剪辑软件里看什么**：

1. 放到两段素材上方的轨道，透明部分能不能看到下面的画面（PNG 序列按图片序列导入；绿幕 MP4 要先加色度抠像）。
2. 颜色有没有偏（钻石块的青绿色、石头的灰色和应用里预览的一样），半透明的边缘有没有发黑。
3. 把完成页写的剪辑点那一帧对齐两段素材的接缝，接缝有没有露出来。
4. 时长对不对（默认 1.1 秒，比模板时长多一帧）。
