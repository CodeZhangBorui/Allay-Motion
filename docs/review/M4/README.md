# M4 界面：评审说明

**做了什么**：06 的完整界面——顶栏（悦灵头像占位、工程菜单：新建/打开/保存/另存为/最近）、模板库（搜索、四个分类、两列卡片、封面与悬停预览由杂务 Worker 生成并按 resourceStamp 缓存、“我的”空状态、右键导出/删除）、预览视口（棋盘格/纯色背景、安全框参考线、适应/100% 缩放、装载超过 180 ms 的悦灵编排、错误卡片带“重置参数”“复制诊断信息”）、播放条（色段、可拖的分界线、剪辑点菱形、可拖播放头、输出规格弹层、高质量预览、静音）、属性面板（由 manifest 自动生成，15 种参数类型各有控件，分组折叠按模板记忆，改过的参数有小圆点可恢复，右键重置/复制/粘贴，预设下拉、更多菜单、另存为模板弹窗含带图片）。撤销重做（zundo，一次拖动一步）、6.7 的全部快捷键、命令面板、设置对话框（五页）、`.allay` 工程文件、资源栈弹层（dnd-kit、Popover）、Sonner 通知、两种语言、两种主题。悦灵五个组件是最终接口加 CSS 占位图形，加载时序是正式逻辑。

**截图**（`pnpm review:m4` 生成；假原版层是纯色色块，悦灵是占位图形，没有任何 Mojang 素材）：`m4-dark-zh`、`m4-light-en`（主界面）、`m4-dark-en-block-picker`、`m4-light-zh-easing`（自定义贝塞尔）、`m4-dark-zh-palette`、`m4-light-en-settings`、`m4-dark-zh-resources`、`m4-dark-en-error`、`m4-light-zh-no-assets`（没有素材的引导）、`m4-dark-zh-mine-empty`、`m4-dark-en-loading`（飞舞编排）、`m4-light-en-min-size`（1120×700）。

**和规格不同**（详见 `docs/decisions.md` M4）：“示例素材”背景禁用（两张示意图不画，待主控和用户决定）；像素字没用上（没有网页可用的像素字体）；T-ALY-2 两条判定字面冲突，按“可以离开后 300 ms 内退场”理解；enum 选项放不下时改用下拉；IPC 没有 `project.create`；“默认输出设置”改的是当前工程；复制值用应用内剪贴板；色板颜色按记忆填写、联网核对失败，**需要人复核**。

**没验证的**：系统窗口按钮的颜色和真实的拖动窗口（只按 M0 的方式自动验证）；所有交互都是 Playwright 经 CDP 发的合成事件，没有人用真实鼠标、触控板、屏幕阅读器试过；截图基线和 axe 只在这台机器的显卡上跑过；悦灵的真实形象、7.5 的十一个位置和四段编排的完整版属于 M5。
