## 做了什么

圆角全为 0；容器和控件是 2 px 缺角描边的方块，凸起和凹陷靠 2 px 的硬边斜面，浮层是 `4px 4px 0` 的硬投影；中性色换成暖紫石头灰和石英/羊皮纸，悦灵青是唯一的强调色，主操作是青色实心块配深色墨字；时间轴的三段是进入青、停留沙、退出紫的平涂色块；标题、按钮、标签页、徽标、数字和时间码用方舟像素字体（12/24，按缩放比例对齐设备像素）；Lucide 图标方头方角、线宽 2.5；过渡 ≤ 120 ms 的分级缓动。规格在 `docs/06-ui-design.md` 6.1、6.2，决定记在 `docs/decisions.md` “界面重设计”。

## 偏离方向的地方

- 控件描边用 `#737080`（浅色 `#857D71`）而不是 `#4A4852`：后者对面板只有 1.7:1；`#4A4852` 只给分隔线。危险色、次要文字、浅色主题的青色文字也各调了一档以过对比度（数字见 decisions）。
- 像素字在 150% 缩放下是 16 px（2 倍点阵），比名义的 12 px 大；参数标签和菜单项仍用 Inter。
- 中间栏很窄（最小窗口）时，24 的时间码退成两行 12 的像素字。
- 预览区四周保持无彩色的中性灰。

## 没验证的

- 只在 150% 缩放下看过；100%、125%、200% 只有换算的单元测试。
- 系统窗口按钮区不在截图里，没在可见窗口里人工看过。
- Windows 高对比度模式下 `box-shadow` 画的描边会消失，没处理。
