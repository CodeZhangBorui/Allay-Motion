## 偏离定稿的地方

1. 第三级文字：稿子的 `#6d6d72` 在面板上只有 3.4:1，不能做文字；文字改用 `#8b8b91`，原值只给图标。所以“转场 · 1.10 s”、规格读数、刻度等比稿子略亮。
2. 面板默认宽度是 280 / 320，稿子是 292 / 336：默认值存在主进程的设置里，这次不改主进程；用户可以拖。
3. 时间轴没有磁吸和缩放（稿子里画了，是新功能，按要求去掉）。
4. 规格读数没有“Alpha”：输出设置里没有这个字段，不编造。音效分组标题右侧没有摘要（“放置 · 破坏 · 80%”）。
5. “翻转”在稿子里是四段的分段控件；我们的选项文字是“竖轴翻转”这类全称，分段放不下，按 4.4 的规则退回下拉。
6. “退出顺序”仍是下拉：它有“与进入相同 / 相反”两个相对选项，画不成固定的图案。
7. 对话框里的确认按钮（导出、保存预设、另存为模板、使用原版素材）仍用强调色实心；“全窗口只有导出一个实心强调色按钮”在主窗口里成立。
8. 预览画面里的方块、模板缩略图、悦灵头像是引擎渲染和占位，与稿子里的示意图不同。
