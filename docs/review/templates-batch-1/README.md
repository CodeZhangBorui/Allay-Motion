# 第 1 批内置模板（抬头显示）的评审

11 个模板：038 标题命令、039 Boss 栏、040 记分板、041 聊天消息、043 状态栏、044 经验收集、045 物品提示框、052 状态效果、053 正在播放、054 调试屏幕、055 声音字幕。每个模板的画面、参数、依据和没做的写在 `docs/templates/<名字>.md`，批次的决定和偏差写在 `docs/templates/batch-1.md`。

## 要看的东西

| 材料 | 在哪 | 含原版素材吗 |
|---|---|---|
| 基准图：每个模板三种画幅（16:9、9:16、1:1）× 五个时刻（0%、25%、中间、75%、100%） | `tests/fixtures/baselines/allay.builtin.<名字>/` | 不含。贴图是假资源栈的纯色块，文字是内嵌 Unifont 的字形（假资源栈没有 Mojangles） |
| 有原版素材时的画面：用本机 `D:\Minecraft\.minecraft` 的 Java 版 26.3 作原版来源，在应用的预览里截的图 | `out/`（不进仓库） | 含。是原版贴图和字体的派生图像，只在本机看，不提交、不外传 |

基准图看位置、大小、动画的时序；`out/` 里的图看贴图和字体在真实素材上对不对。两份都没有在剪辑软件里看过。

## 每个模板要判断什么

请对照游戏里的实际画面（同样的界面缩放），逐条回答“像 / 不像（哪里不像）”。

| 模板 | 要判断的 | 最没把握的（凭记忆的数值） |
|---|---|---|
| 038 标题命令 | 标题、副标题、动作栏三行的大小和高度；淡入淡出的快慢 | 标题在中心上方 40、副标题在下方 10 个界面像素；动作栏显示 3 秒（Wiki 说约 1.5 秒，标着“需要更多信息”） |
| 039 Boss 栏 | 栏和名字的位置、多条时的间距；进度条裁切；分段刻度叠在进度上的样子 | 第一条在 y = 12、名字在上方 9、间距 19；进度像素的取整 |
| 040 记分板 | 右侧的竖直位置、黑底的深浅（标题行更深）、红色分数右对齐；换位那一刻 | 竖直居中的公式、30% / 40% 的底、同分时按名字排 |
| 041 聊天消息 | 左下角的位置、行高、黑底宽度；消息淡出的时机；输入栏和光标 | 消息 10 秒后淡出（Wiki 没查到 Java 版的说法）、淡出的曲线、输入栏的颜色 |
| 043 状态栏 | 心、护甲、饥饿、气泡四排的位置和间距；掉血时的闪白、低血量的抖动；各种心的贴图 | 闪白持续的刻数和节奏、抖动的规律、多排心时的行距公式 |
| 044 经验收集 | 经验条和绿色等级数字的位置；条按像素涨；经验球的颜色和透明度 | 等级数字的颜色 #80FF20 和黑边、经验球的染色公式和 50% 透明。**经验球飞向经验条是这里自己设计的**（游戏里经验球在世界里） |
| 045 物品提示框 | 两种框（1.21.1 及更早的渐变框、1.21.2 起的贴图框）；文字的行距和第一行下面的空隙；跟鼠标的偏移 | 渐变框的颜色和边框位置、贴图框外扩 9 像素、提示框在鼠标右上 (12, −12) |
| 052 状态效果 | 右上角两排图标的位置；信标效果的蓝框；快结束时的闪烁节奏 | 闪烁的公式、正负面效果的分类、一半效果的中英文名没对照语言文件 |
| 053 正在播放 | 动作栏的彩虹文字的变色速度和饱和度；**音乐提示框整个是近似**（没查到它的版式），值不值得保留 | 彩虹的色相速度、饱和度 0.7、亮度 0.6；提示框的全部尺寸和时长 |
| 054 调试屏幕 | 两栏的位置、灰底和字色；坐标、朝向、帧率的格式和变化 | 灰底颜色、小数位数、默认文字里固定的那几行是示意 |
| 055 声音字幕 | 右下角字幕框的位置、80% 黑底、箭头；字从白变灰的快慢 | 全部版式数值、3 秒、灰度 255 → 75、不带阴影（较新版本可能不同） |

## 还要用户决定的

- 053 的音乐提示框：版式是近似的，留着（文档里写明“近似”），还是先拿掉、等查到数值再做。
- 052 物品栏样式（带名字和剩余时间的那种）这次没做：贴图在 1.21.1 和 26.3 之间换过，版式数值也记不准。要不要排进后面的批次。
- 所有模板都只有 Java 版的样式，基岩版一个都没有做（只查到零星的文字描述，没有版式数值）。
- 带文字的预设只有中文（预设的参数值不分语言），英文界面下也是中文。改成双语需要预设支持多语言文字，是公共改动。
