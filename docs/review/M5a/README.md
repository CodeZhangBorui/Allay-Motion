# M5a 评审材料：悦灵的形象与动作（H-ALY）

**怎么生成**：`pnpm mascot:bake`（不显示的窗口里渲染，约 25 秒）。贴图来自本机游戏的 jar（这台机器上是 1.21.1），没装游戏时加 `--download` 从 Mojang 官方服务器取。产物都是原版贴图的派生图像，按用户决定不提交，所以 `out/` 被 git 忽略，看之前要先跑一次。

**看什么**（都在 `docs/review/M5a/out/`）：

- `mascot-contact-sheet.png`：前四行是 hover、fly、dance、sad，每 3 帧取一帧（缩到一半）；最后一行是正面头像 48/32/24/20/16（每个尺寸先睁眼、后闭眼），再是应用图标 256/128/64/48/32/16。
- `allay-hover.apng`、`allay-fly.apng`、`allay-dance.apng`（以及 `allay-sad.apng`）：288 px、30 fps、循环播放，深色底。用浏览器打开就能看动画。
- 全尺寸的图集和图标在 `packages/mascot/generated/`。

**请人判断**：

1. 悦灵的样子是否可以接受（朝右、转向镜头 28°、俯角 8°；面的明暗）。
2. 动作是否自然：hover 浮动和扇翅、fly 前倾、dance 转圈加摇摆和举手、sad 低头和垂翅。
3. 循环播放时首尾是否无缝（自动测试按 T-ALY-1 量过，但没有人眼看过）。
4. 闭眼版头像（原版没有闭眼贴图，从原图派生成“眯眼”）是否可接受，还是不要眨眼。

**和规格不同的地方**：贴图用原版而不是自绘（用户决定，产物会进安装包，加重了发布前的 H-BRAND）；模型尺寸按原版贴图的布局；翅膀不透明（原版像素如此）；联络图放在被忽略的目录。详见 `docs/decisions.md` 的 M5a 小节。
