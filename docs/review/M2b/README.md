# M2b 评审说明

**做了什么**：资源栈接进引擎和界面。主进程 `resources`/`cache` IPC 与资源栈服务（设置里的资源栈、`resourceStamp` 变化推给渲染进程）；贴图在渲染进程解码后交给引擎 Worker，删除了 M1 自己画的占位桩；`.mcmeta` 动画（每个子帧更新 UV）；方块与物品网格、精灵九宫格、位图字（资源栈字体优先，缺字回退到方舟像素字体，OFL-1.1，原样随包）；缩略图与磁盘缓存；资源栈弹层、拖入资源包、首次发现本机游戏的询问、没有素材时的引导状态、原版下载（点了才联网，带进度、取消、失败文案）。临时方块擦除模板改用 `ctx.resources.block`。

截图（`pnpm build && pnpm review:m2b` 重新生成，全部是**测试脚本生成的纯色假数据**，没有 Mojang 素材）：`m2b-onboarding.png` 没有素材时（品红黑是缺失占位）；`m2b-fake-vanilla.png` 只有假原版层；`m2b-resource-stack.png` 假原版层 + 一个假资源包，弹层打开。

**本机冒烟**（`pnpm review:m2b --real`，只读本机 `%APPDATA%\.minecraft`，不联网）：检测到 1.21.1，原版层生效，预览显示原版钻石块贴图，`warnings` 为空；关掉原版层后变回占位。截图在 `docs/review/M2b/out/`，**含原版贴图，被 git 忽略，不提交**。

**和规格不同**（详见 `docs/decisions.md` M2b）：T-AST-2 前提改为“只有一个假原版层”，T-AST-7、H-ART 不做；对话框第二个按钮“先用内置素材”改为“暂不使用”；文字是一段一张贴图而不是每字形一个四边形；面明暗与着色在线性空间里乘（与游戏的 sRGB 相乘差几个单位）；弹层排序用上移/下移按钮、内置层（空）不列出；IPC 多了 `readTexture`、`fontProviders`、`fallbackFont`、`chooseGameDir`、`downloadVanilla`、`cancelDownload`；下载缓存的原版层不按需联网取音效；“约 45 MB”是估计。

**没验证的**：真实下载只在 M2a 的冒烟脚本里跑过，没经界面对真实服务器下载过；“选择游戏目录”和“添加资源包…”两个对话框路径没有自动化测试；字体只用假字体和方舟字体测过，原版 `ascii.png` 等的文字效果没在应用里看过；高清资源包、旧版格式包没用真实包试过；缩略图还没有界面用到。一次完整 e2e 里 T-ARC-5 的 CDP 往返量到约 1 秒（随后单独 7 次、完整 `pnpm check` 一次都通过），原因没查清。

**请人确认**：在装了游戏的机器上打开应用，同意使用原版素材后，打开“素材”弹层**开关原版层，预览应当在原版钻石块和品红黑占位之间切换**；再拖进一个自己的资源包，它应当盖在原版之上。
